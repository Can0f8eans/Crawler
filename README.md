# Crawler
A CLI Dungeon Crawler, with wholly randomly-generated floors

This is just a pet project involving python and classes.
My goal was to create a randomly generated dungeon with a theoretical infinite amount of floors.
You're goal is to get as far as you can.

# Pre 1.0 Release
This is a pre-alpha release, as such it is chock full of bugs. If you wish, you can post a concise bug report 
and commit it to the bug section of the repo. Just include the release you used and what you were doing when you encountered
the bug!

# Development
I intend to keep working on Crawler until I deem it somewhat decent. My plans include adding a personal leaderboard
to allow you to keep track of your stats as a whole. I also intend adding little quality of life features suggested
to me by players. 

If you'd like to offer help or give critiques, please add a commit to the development branch!
